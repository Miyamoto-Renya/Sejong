# RX 6600에서 4B Sejong을 학습하기 위한 미분·메모리 구조 연구

2026-11-01. 연구 대상은 무작위 초기값에서 시작하는 다음 byte 예측 학습이다. 목표는 RX 6600 한 장에서 정해진 언어 품질에 도달하는 시간을 줄이는 것이다. 모델의 총 학습 가능 파라미터, 입력당 사용 용량, 실제 갱신된 용량을 각각 집계한다.

후속 [FLOPs 연구](flops-learning.md)는 이 문서의 예측 미분을 인수 형태로 누적하는 계산법과, 독립 보조 모델을 사용해 본체의 순전파·역전파 횟수를 함께 줄이는 후보를 다룬다. 주요 연산량과 기울기 변동을 기준으로 연구 우선순위를 구체화했다.

이번 조사에서 우선 구현할 후보로 **연산별 수정 신호 예측, 표본 역전파를 통한 잔차 교정, 인과적인 구간별 기억 페이지 선택**을 선정했다. 계산 경로와 메모리 이동을 함께 줄이는 구성이다. 기울기 교정의 계보에는 synthetic gradients와 control variates가 있다. Sejong에서 검증할 설계 가설은 연산의 출력에 대한 미분을 예측하는 방식, 두 수정 신호를 분리하는 역전파, byte 구간별 페이지 선택의 결합이다.

먼저 앞서 제안했던 소수 방향미분의 비용을 계산했다. 차원 D의 고정 기울기를 g, 독립 Rademacher 벡터를 v라고 하자. 각 좌표는 같은 확률로 −1 또는 +1이다. 방향미분으로 얻는 추정량은 다음과 같다.

\[
\widehat g=(v^\top g)v,\qquad
\mathbb E[\widehat g]=g,\qquad
\mathbb E\|\widehat g-g\|^2=(D-1)\|g\|^2.
\]

k개의 독립 추정량을 평균하면 마지막 식을 k로 나눈다. D=4,000,000,000, k=32에서는 상대 평균제곱오차가 약 1.25×10⁸이다. 계산은 `E[vvᵀ]=I`, `||v||²=D`에서 바로 나온다. 고정 저차원 부분공간을 사용하는 방향은 그 공간으로 투영한 기울기를 얻는다. 해당 부분공간이 실제 수정 방향을 얼마나 포착하는지가 새로운 측정 대상이 된다. 이 결과에 따라 우선 후보를 수정 신호 예측과 표본 교정으로 좁혔다.

핵심 규칙은 **누적 배치 전체의 저렴한 예측에, 일부 배치에서 측정한 잔차 평균을 더하는 것**이다. 하나의 optimizer step에 동일 길이 microbatch M개가 있고, 각 microbatch의 정확한 평균 기울기를 gᵢ, 예측 기울기를 cᵢ라고 하자. 가중치와 예측기 상태를 이 M개에서 고정한다. m개 인덱스의 집합 C를 전체에서 균등 비복원 추출한다.

\[
\widehat G = \frac1M\sum_{i=1}^{M}c_i
             +\frac1m\sum_{i\in C}(g_i-c_i).
\]

각 인덱스의 포함 확률이 m/M이므로, 관측한 데이터와 고정 예측을 조건으로 평균을 취하면 다음이 성립한다.

\[
\mathbb E_C[\widehat G]=\frac1M\sum_i g_i=G.
\]

rᵢ=gᵢ−cᵢ, r̄=M⁻¹∑rᵢ, Sᵣ²=(M−1)⁻¹∑||rᵢ−r̄||²로 두면 유한 모집단 표본 평균의 분산은 다음과 같다.

\[
\mathbb E_C\|\widehat G-G\|^2
  =\frac{1-m/M}{m}S_r^2.
\]

이 식에서 줄여야 할 양은 **microbatch 사이에서 변하는 예측 잔차**다. 모든 microbatch에 같은 예측 편향이 더해졌다면 잔차가 일정해져 제어 표본 하나로도 그 편향을 정확히 교정한다. 페이지별로 기울기 지지 집합이 달라도 같은 식이 적용된다. 제어 표본이 적을수록 잔차의 변동을 더 크게 반영한다.

실행 계약은 다음과 같다.

1. optimizer step 시작 시 모델 가중치, 예측기, microbatch별 난수와 route를 고정한다. 제어 표본 수 m은 이전 step의 측정값으로 정한다.
2. 제어 집합을 균등 비복원 추출한다. M개 microbatch 모두에 같은 순전파와 손실 정의를 적용한다.
3. 제어 표본에서 정확한 미분을 얻고, 전체 표본에서 예측 수정 신호를 얻어 위 식으로 누적한다.
4. M개 관측의 누적이 끝나면 모델을 갱신한다. 측정한 정확한 미분으로 예측기를 학습하고 다음 step에 적용한다.
5. checkpoint에 제어 표본 RNG, 예측기, 제어 수 결정에 쓰는 통계와 페이지별 optimizer 상태를 저장한다.

길이가 다른 microbatch에는 유효 byte 수에 비례한 wᵢ를 적용한다. 그때 식은 `Σ wᵢcᵢ + (M/m) Σ_{i∈C} wᵢ(gᵢ−cᵢ)`가 된다. 같은 배치의 제어 표본을 관찰한 뒤 cᵢ를 다시 피팅하면 표본 선택과 예측이 결합한다. 수치 검증에는 이 경우 평균이 실제 기울기의 1/4로 바뀌는 예도 포함했다.

평균 등식의 대상은 optimizer에 전달하는 기울기다. Adam의 제곱·나눗셈, clipping과 양자화는 그 뒤에 적용하는 별도 변환이다. 초기 수치 비교는 같은 SGD 또는 이전 상태로 고정한 전처리 행렬을 사용한다. Adam·factored 상태를 적용할 때는 같은 optimizer를 쓴 정확한 미분 실행과 비교하고, 교정으로 증가한 2차 moment와 clipping 비율을 기록한다.

가중치 전체를 예측하는 보조 모델의 저장량을 줄이기 위해, 각 연산 출력에 대한 미분을 예측한다. 선형 연산 Z=XW의 정확한 출력 미분을 δ, 예측값을 c라 두면 예측 가중치 기울기는 `Xᵀc`다. 이렇게 하면 보조 모델의 출력 차원이 해당 연산의 hidden 폭으로 정해진다.

일반 microbatch에서 가중치 누적에 사용하는 출력 신호는 `c/M`이다. 제어 microbatch에서는 다음 신호를 사용한다.

\[
\delta_{\mathrm{update}}=\frac{\delta}{m}
              +\left(\frac1M-\frac1m\right)c,
\qquad
\Delta W_{\mathrm{accum}}=X^\top\delta_{\mathrm{update}}.
\]

이 식은 `Xᵀc/M + Xᵀ(δ−c)/m`와 같아 가중치 행렬곱 하나로 교정을 누적한다. 제어 실행에서 이전 연산으로 전달하는 신호는 정확한 `δWᵀ`다. **가중치 갱신용 신호와 이전 연산으로 전달할 신호를 구분하는 역전파 인터페이스**가 구현의 중심이 된다. 현재 `Graph::propagate`의 단일 `dy` 경로를 이 계약에 맞춰 확장한다.

일반 microbatch는 각 선형 연산의 가중치 미분을 계산하고, attention·RoPE·SwiGLU를 가로지르는 오차 전달을 생략하는 실행 모드를 갖는다. Norm의 scale 미분과 embedding의 행 누적도 각 출력의 예측 신호로 구한다. 마지막 출력 head는 저렴한 정확한 미분을 사용한다. 제어 microbatch는 전체 그래프의 정확한 신호를 전파한다. 여러 연산으로 구성된 기억 모듈의 내부 미분과 두 신호 처리 비용은 별도로 계측한다.

예측기의 첫 설계는 rank r=32의 작은 행렬들로 구성한다. 입력 X, 연산 출력 Z, 최종 softmax 오차 E=`p−onehot(y)`, 같은 문서 안에서 뒤쪽 오차를 평균한 S를 사용한다.

\[
C=\tanh(XA+ZB+EU+SV+b)D.
\]

A는 `d_in×r`, B는 `d_out×r`, U와 V는 `257×r`, D는 `r×d_out`다. 예측 신호는 유효 byte 수로 나누어 해당 손실 정규화와 맞춘다. S는 이전 위치의 K/V가 이후 위치의 손실에 미치는 영향을 요약하기 위한 가설이다. E와 S는 학습 시 수정 신호 생성에 쓰며, 추론 함수는 입력 prefix와 모델 가중치로 실행한다. 예측기의 감독 목표는 제어 실행에서 얻은 정확한 출력 미분이다. 예측기 학습에서는 X·Z를 상수로 취급한다.

이 예측기는 입력 미분을 계산하는 작업을 줄이고 가중치 미분 계산을 유지한다. 선형 연산의 순전파 비용을 F로 잡으면 기본 산술은 `순전파 F + 입력 미분 F + 가중치 미분 F = 3F`다. 제어 비율 p=m/M, 예측기·감독·통계 비용 H를 포함한 제안의 산술 모형은 `2F+pF+H`다. 기억 모듈 내부 미분, attention, 페이지 이동과 동기화는 별도 항이다. 현재 checkpoint 재계산은 추가 순전파 항으로 집계한다.

뒤에서 정하는 4B 형상과 rank 32 예측기에 대해 행렬곱 수를 계산했다. 예측기 순전파는 0.1191F, 제어 표본 한 개의 예측기 학습은 0.1549F다. 예측기 입력을 고정하면 학습 시 각 행렬의 가중치 미분과 마지막 투영의 입력 미분을 계산한다. 따라서 이 산술 모형의 H는 `(0.1191+0.1549p)F`다. 다음 표는 해당 형상에서 얻은 행렬곱 비용의 민감도 계산이다.

| 제어 표본 / 8 | 정확한 3F 대비 비용 | step 산술 속도 비율 | 계산×분산 기준의 잔차 분산 비율 경계 |
| --- | ---: | ---: | ---: |
| 1 | 0.7545 | 1.3254 | 0.0465 |
| 2 | 0.8026 | 1.2459 | 0.0820 |
| 4 | 0.8989 | 1.1125 | 0.1125 |
| 8 | 1.0913 | 0.9163 | 예측기 수집 비용을 포함한 정확한 미분 |

마지막 열은 독립 microbatch의 기울기 분산 σg²와 잔차 분산 σr²의 비율 q=σr²/σg²를 사용한다. 같은 M에서 추정 분산의 비율은 `1+(1/p−1)q`가 된다. 비용 비율 γ와 곱한 `γ[1+(1/p−1)q]<1`을 후보 선별 기준으로 썼다. 언어 손실에 도달하는 시간은 실제 학습 곡선으로 판정한다. m=2의 예에서는 중심화한 잔차 분산이 원래 기울기 분산의 약 8.20% 아래일 때 이 계산 기준을 통과한다. 워밍업에서는 m=8로 신호를 모으고, m=2 이상에서 표본 잔차 분산을 추적해 제어 수를 조절한다. 실제 H에는 optimizer·점별 연산·통계 수집·메모리 이동도 포함한다.

4B 용량의 저장·활성 구조도 함께 정했다. 공통 본체는 기존 byte Transformer 형상을 확장하고, 네 위치에 학습형 기억 bank를 삽입한다. 모든 본체·router·기억 가중치는 초기값부터 학습한다.

| 구성 | 제안 형상 | 파라미터 |
| --- | --- | ---: |
| 공통 본체 | d=1024, 12층, 16 heads, FFN=2048, vocabulary=257 | 126,381,056 |
| 기억 | 4 banks × 7,396 pages × (1024×64 + 64×1024) | 3,877,634,048 |
| product-key router | bank마다 두 개의 86×512 key 집합 | 352,256 |
| 추론 모델 합계 | 서로 독립적인 학습 가중치 합 | 4,004,367,360 |
| 학습 보조 예측기 | rank 32, 선형 연산·norm·embedding·기억 출력에 연결 | 15,018,688 |

기억 page는 `GELU(xK_page)V_page`를 계산하는 hidden 폭 64의 모듈이다. bank는 3·6·9·12번째 Transformer 블록 뒤에 둔다. 별도 학습 scale을 가진 norm 대신 고정 RMS 정규화로 router 입력 q를 만든다. q를 512차원씩 나누어 각 key 집합과 내적하고, 두 점수의 합으로 86×86개 page의 점수를 정의한다. 두 key 집합에서 각각 상위 2개를 구해 4개 조합을 비교하면 전체 상위 2개 조합을 얻는다. 같은 점수는 page ID로 순서를 정한다.

선택된 두 page 점수에 softmax를 적용하고, page 출력의 가중 합을 residual 경로에 더한다. 초기 residual 배율은 고정된 설정 값으로 저장한다. 학습 초기의 탐색은 입력 내용과 독립인 난수로 일부 선택 슬롯을 교체하는 방식으로 설계하고, 선택 난수는 제어 실행과 공유한다. 선택 경계 안의 경로에 대해 미분하며, 탐색 비율과 페이지 부하에 따른 학습 목표의 변화를 별도 기록한다. 파라미터 중복 공유가 있는 후속 설계에는 고유 저장 가중치 수를 다시 집계한다.

핵심적인 시스템 설계는 **32-byte 구간의 첫 위치에서 page를 선택하고, 그 구간 안의 32개 위치가 선택을 공유하는 것**이다. 첫 위치의 hidden은 해당 prefix에서만 계산한다. 이후 위치는 각자의 hidden으로 page를 실행하므로 출력은 위치별로 다르다. 구간의 경계는 문서 시작에서 정하고, 학습 crop에는 절대 구간 offset과 필요한 왼쪽 prefix를 포함한다. 생성 시에는 현재 구간의 선택과 offset을 KV cache와 함께 보관한다. 이 규칙으로 학습과 생성의 page 선택을 일치시킨다.

512-byte 관측 하나가 bank마다 두 page를 선택한다고 하자. 선택은 각 결정에서 균등하고, 결정끼리 독립이며, 가중치 cache hit가 0인 계산 조건을 쓴다. E개 page에서 R번 top-k 선택한 고유 page 수의 기대값은 `E[1−(1−k/E)^R]`다. FP32 page 하나는 0.5 MiB다.

| 선택을 공유하는 구간 | 가중치 H2D | 가중치 H2D + 같은 크기 기울기 D2H | 8회 누적의 page gradient 최대 크기 |
| --- | ---: | ---: | ---: |
| 1 byte | 1,912.79 MiB | 3,825.58 MiB | 14,792 MiB |
| 8 bytes | 253.83 MiB | 507.66 MiB | 2,048 MiB |
| 32 bytes | 63.87 MiB | 127.74 MiB | 512 MiB |

가중치 이동과 기울기 복사를 합친 127.74 MiB는 유효 전송률을 4·8·12 GB/s로 가정할 때 각각 33.49·16.74·11.16 ms다. 이 전송 시간에는 page lookup, host optimizer, 할당·동기화가 추가된다. 표의 512-byte 관측은 구간 경계에서 시작한다. 임의 위치 crop에 붙이는 prefix의 계산과 이동은 실행에서 따로 집계한다. 실제 route 중복과 cache hit는 전송량을 바꾼다. 32-byte 공유가 언어 품질에 미치는 영향을 span 1·8과 대조한다. 구간별로 선택된 page에 모인 모든 관측을 사용해 기울기를 누적한다.

한 byte에서 선택되는 기억 파라미터는 1,048,576개다. 상주 공통 본체·router와 합한 용량 집계는 127,781,888개다. 총 용량과 선택 용량의 비율은 아키텍처의 계산 경로를 설명한다. 언어 능력은 고정한 검증 문서의 bits-per-byte와 후속 과제로 측정한다. 기억의 실제 학습량은 page별 방문 수·갱신 norm·관측 다양성과 사용량 분위수로 집계한다.

상태 저장은 다음처럼 구성한다. host의 FP32 기억 가중치가 원본이며, GPU cache는 version을 가진 page 사본을 보관한다. 한 optimizer step 동안 가중치 version을 고정한다. GPU에서 관측별 page 기울기를 합친 뒤 host의 해당 page 버퍼에 누적하고, 8개 microbatch가 끝나면 host가 선택된 page를 갱신한다. 이후 해당 GPU 사본의 version을 갱신하거나 cache에서 제거한다. 전체 기억의 초기화·저장·복원도 page 단위로 스트리밍한다.

기억의 2차 moment는 행·열 통계를 사용하는 [Adafactor](https://arxiv.org/abs/1804.04235) 계열을 후보로 둔다. page의 방문 횟수로 decay를 진행하는 정책, clipping·epsilon·weight decay를 명시한다. 이 정책은 정확한 미분 비교 실행에도 동일하게 적용한다. 초기 교정식 검증은 SGD로 수행하고, optimizer 확장은 별도 실험 축으로 둔다.

단계 2·3은 저장소의 전체 byte Transformer를 사용한다. 단계 4·5의 구현은 4B 형상에 맞는 초기화·학습·optimizer·checkpoint·생성을 함께 다룬다. 원본별 학습과 상태 편입이라는 Sejong의 설계 원리를 학습형 기억에 적용한다. 현재 native 의미 파서·확률 합성 경로는 별도의 입출력 계약을 유지한다.

자료는 학습·검증 문서 단위로 고정하고, byte 수·언어 구성·중복 처리·fingerprint를 기록한다. 같은 초기값·표본 순서에서 정확 미분, 예측만, 제어 교정을 비교한다. 희소화 효과와 미분 변경 효과는 동일한 page 구조의 정확 미분 실행을 기준으로 분리한다. m=8→4→2의 결정에는 측정한 H와 q를 사용하고, span=1·8·32는 같은 자료량에서 비교한다. 최종 채택은 검증 손실과 필요한 언어 과제의 목표 품질에 도달한 총시간으로 정한다.

이번 계산은 연구의 초점을 두 군데로 좁혔다. **학습 규칙에서는 예측 잔차의 변동을 낮추는 것, 시스템에서는 학습 구간 안의 page 재사용을 높이는 것**이다. 첫 구현에서 얻어야 할 핵심 숫자는 예측 비용 H, 중심화한 잔차 비율 q, host↔GPU 전송량, 그리고 같은 품질까지의 시간이다.
